Upon running, first resize the terminal to your desired size. Second, use the arrow keys to resize the green box until it's as large as it can be within the terminal, and hit enter.

Controls:
- Up/Down: Move the green paddle up and down
- W/S: Move the red paddle up and down

Known issues:
- As the launcher is a simple .bat file, you may need to change the word 'python' to whatever you use on your PC. Common names are py and python3
- The ball phases slightly into the left paddle when it hits it. Mostly just a graphical issue, but it can be annoying.
- All keyboard inputs are blocked everywhere except for the game screen. This is to prevent you from interacting with the terminal behind the game. However, this also means that if you tab out of the game you won't be able to control things properly. To fix this, simply close the game.
